How it works: the skill sends your last prompt + AI response to a detection engine that classifies 15 algorithmic dark patterns across 7 canonical categories defined from lived experience. Each detection returns a frustration score. Results are logged to a public dashboard. Claude then reads the findings and self-corrects for the rest of the session.
